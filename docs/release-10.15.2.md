# v10.15.2 空闲联动修正

修复没有任务时仍点平板：合并版不再读取全局旧 Hooks 状态目录，因此旧的一小时执行记录不能覆盖当前聊天的空闲状态。

会话适配器启动时读取末尾最多 8 MiB 的记录，恢复仍在进行的任务；已经结束或中断的聊天直接待机，不重播历史结束提示。只有明确开始的任务才能被工具事件更新，迟到的孤立工具事件不能重新唤起执行动作。结束提示播放一次后转为持续刷新的空闲信号；适配器退出后，状态最多十秒过期。保持原有一小时无相关事件的活跃状态上限，超时后归于空闲。

默认可跟随指定项目最近活动的主聊天，每三秒检查最近七天的会话目录；子代理及其他项目排除在外。找不到新聊天时保留指定会话。使用 `tools/Configure-Session.ps1 -ProjectPath 'C:\项目'` 配置项目，`-FixedSession -SessionPath '会话路径'` 可固定一条聊天。旧的固定会话配置仍兼容。切换项目需要重新配置；同时运行多个聊天时按最近写入的主聊天选择，不是聚合任务管理器。

记录仅输出状态、时间、散列标识；不保存聊天正文、命令或工具结果。媒体和气泡沿用 v10.15.1，新增生成费用为零。检查范围及结果见本版本 `publish-verification.json`；原生 Hooks 完整回调及图像细节的用户验收不因此成立。
