# v10.9 · 持续思考与阅读版

思考和阅读保持活动姿势持续循环，阅读加入翻页与脚边书堆，约随机2～5分钟真实放书取书再继续阅读。暂停、菜单、隐藏不累计换书时间。自动换书可被提问打断，互动结束后恢复助手状态。

修复预读帧被LRU提前淘汰导致的反复解码：在可见阅读测试中，原计时设置9秒补帧等待40→0，提交画面494→520，另两轮补帧等待也为0。缓存容量保持原限制。切换期间新动作继续播放，过渡结束不倒回第一帧。113段原生切换、24种中途过渡、6种动态过渡及八组验收通过。

强制打断的身体轮廓混合已减少，五官纹理交接缩短；大姿势仍可能短暂变软或重影。本版没有验证当前云端调度会话的 Codex 原生 Hooks，以 Windows 客户端控件事件补充验证；控件观察与原生回调分别记录。
